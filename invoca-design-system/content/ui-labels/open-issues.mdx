## Gaps in the current rules

| Gap | Why it matters | Status |
|---|---|---|
| **No word-count ceiling for non-button labels.** Button has one (1–3 words); no equivalent has been stated for a checkbox option, a tab name, or a column header. | Without one, an unusually long option label is a style choice on one screen and a bug on another. | Open |
| **No pluralization convention.** Whether a section is named "Setting" or "Settings" is not addressed anywhere. | A small, constant source of inconsistency across a large surface of labels. | Open |
| **No truncation-safety guidance for translated or localized labels.** Every length guidance so far assumes English. | A label that fits in English at 3 words may run considerably longer in another language. | Open |
| **The verb/noun table is a synthesis, not a rule stated anywhere directly.** No single source states the general principle; this page is what makes it explicit and citable in one place. Needs sign-off before treating it as more than a strong pattern. | Six pages agreeing independently is strong evidence, not confirmation. | Open |
