  36px, leaving 22px for the text line box — close to `body2`'s 20px line-height but not an
  exact match. Unlike [Button](/invoca-design-system/components/actions/button#tokens), this session could not
  measure the rendered box directly, so treat 22px as an estimate, not a verified effective
  value. Confirm against a live render before citing a specific number.
</Warning>

<Warning>
  **`form-field-focus-ring-error`'s light-mode value (`#ed3036`) exactly matches
  `border-error`'s *dark*-mode value**, not its light one (`#e4131b`). One of two things is
  true: either the focus ring intentionally uses a different red than the border for contrast
  reasons and the match to dark's `border-error` is coincidence, or the focus-ring token is
  reading the wrong colour scheme. See
  [TITAN-DIV-24](/invoca-design-system/foundations/divergences#titan-div-24) — direction is to check the lookup,
  not to guess.
</Warning>
