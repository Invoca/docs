Radio shares its checked/selected fill and disabled treatment with
[Checkbox](/invoca-design-system/components/forms/checkbox#tokens) — `icon-selected` (`#2666f9`) and
`icon-disabled` (`#a1a7b2`) are not re-declared here.

| Token | Value | Renders as |
|---|---|---|
| `form-input-radio-group-offset` | `-0.5rem` (-8px) | A negative offset applied to a Radio group's container — pulls the group inward, likely compensating for each Radio's own hit-target padding so the group's visual edge lines up with sibling fields. |
| `form-control-label-min-height` | `28px` | The row height pairing a Radio with its label — shared with [FieldLabel](/invoca-design-system/components/forms/field-label#tokens) and [Checkbox](/invoca-design-system/components/forms/checkbox#tokens). |
| `form-input-disabled-opacity` | `0.5` | Applied to a disabled Radio. |

<Info>
  **No Radio-specific colour token was found beyond what Checkbox already uses.** Both share
  `icon-selected`/`icon-disabled`, which is consistent with the Figma library naming both
  controls' composite the same way (`Selected=true/false`) — see
  [Vocabulary](/invoca-design-system/components/forms/radio#vocabulary).
</Info>
