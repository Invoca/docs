Select's closed trigger renders through the same field chrome as a text field — control
height, border width, and focus ring are not re-declared here. See
[Input](/invoca-design-system/components/forms/input#tokens) for those.

| Token | Value | Renders as |
|---|---|---|
| `select-min-width` | `100px` | A floor on the closed trigger's width — does not grow it, only stops it collapsing below this. |
| `select-group-label-padding` | `6px 16px` | The heading row inside a grouped option list. |
| `select-group-label-font-size` | `0.875rem` (14px) | Group heading text. |
| `select-group-label-font-weight` | `500` | Group heading weight — Titan's own value, distinct from [FieldLabel](/invoca-design-system/components/forms/field-label#tokens)'s field-label weight and not carrying its `px`-unit defect. |
| `select-group-label-line-height` | `1.5rem` (24px) | Group heading line height. |
| `searchable-select-width` | `300px` | The trigger width when `Autocomplete` is on — see below. |

<Note>
  **Updated after checking the Figma library.** An earlier pass of this page could not confirm
  whether `searchable-select-width` belonged to Select or to a separate, undocumented
  "Combobox." The design library models autocomplete as an `Autocomplete` variant on the same
  `Select Input` component — not a different one — which is consistent with this token being
  Select's own. Still needs sign-off against source: see
  [Known issues](/invoca-design-system/components/forms/select#known-issues).
</Note>
